📝 เฉลยปรนัย — สแกนตรวจกระดาษคำตอบด้วยกล้อง

← กลับแดชบอร์ด

แต่ละวิชามีเฉลย จำนวนข้อ และกระดาษคำตอบของตัวเอง — เลือกวิชาก่อนพิมพ์หรือสแกน

ตั้งค่าข้อสอบ

เฉลย

กดตัวเลือกเพื่อกำหนดเฉลย (กดซ้ำเพื่อยกเลิก) ข้อที่ไม่ได้ตั้งเฉลยจะไม่นับคะแนน · บันทึกในเครื่องอัตโนมัติ

กระดาษคำตอบ

พิมพ์แล้วให้ผู้สอบระบายวงกลมให้ทึบด้วยปากกาหรือดินสอสีเข้ม ห้ามตัดหรือบังสี่เหลี่ยมดำที่มุมทั้ง 4 ด้าน · ในหน้าต่างพิมพ์ให้ตั้ง "หน้าต่อแผ่น = 1" และสเกลเป็นค่าเริ่มต้น/100%

กด "เปิดกล้อง" แล้วถือกระดาษคำตอบให้เห็นสี่เหลี่ยมดำครบ 4 มุม
ยังไม่ได้เปิดกล้อง

เขียว = ถูก · แดง = ผิด · วงฟ้า = เฉลยที่ถูก (เมื่อตอบผิดหรือเว้นว่าง)

ตรวจทาน / แก้คำตอบที่ระบบอ่านได้

ถ้าระบบอ่านผิดหรือผู้สอบลบรอยไม่สะอาด แตะตัวเลือกเพื่อแก้ คะแนนคำนวณใหม่ทันที

บัญชีและคลาวด์ (Supabase)

โหลดไลบรารี Supabase ไม่ได้ (ออฟไลน์?) — ยังใช้งานแบบเก็บในเครื่องได้ตามปกติ

ยังไม่ได้เชื่อม Supabase — ใส่ค่าจาก Project Settings → API (ผู้ดูแลตั้งครั้งเดียว)

ต้องเข้าสู่ระบบที่เว็บโรงเรียนก่อน แล้วกลับมาหน้านี้ไปหน้าเข้าสู่ระบบ

ใส่อีเมลอย่างเดียว ไม่ต้องใช้รหัสผ่าน — ระบบส่งลิงก์ให้ กดลิงก์ในอีเมลแล้วจะเข้าสู่ระบบอัตโนมัติ (ครั้งแรกจะสร้างบัญชีให้เอง) · ถ้าไม่เห็นอีเมล ให้ดูในกล่องจดหมายขยะ

เข้าด้วยรหัสผ่านแทน (ไม่บังคับ)

ไม่เข้าสู่ระบบก็ใช้ได้ ข้อมูลจะเก็บในเครื่องนี้อย่างเดียว · เข้าสู่ระบบแล้วเฉลยและผลสอบจะซิงก์ข้ามเครื่องและเป็นของครูคนนั้นเท่านั้น

👤

ผลสอบที่กด "บันทึก" และเฉลยที่แก้ จะส่งขึ้นคลาวด์อัตโนมัติ · ข้อมูลในเครื่องยังอยู่หลังออกจากระบบ

วิธีตั้งค่าฝั่งผู้ดูแล (ทำครั้งเดียว)
  1. สร้างโปรเจกต์ที่ supabase.com
  2. เมนู SQL Editor → วางโค้ดด้านล่าง → Run (สร้างตารางและกำหนดให้ครูเห็นเฉพาะข้อมูลของตัวเอง)
  3. Project Settings → API คัดลอก Project URL และ anon public key ใส่ในช่องด้านบน หรือในไฟล์ config.js
  4. Authentication → URL Configuration ตั้ง Site URL เป็นที่อยู่เว็บแอป (เช่น https://pdosndata.github.io/omr-scanner/) และเพิ่มที่อยู่เดียวกันใน Redirect URLs — ไม่ตั้งค่านี้ ลิงก์ในอีเมลจะพาไปผิดที่
  5. Authentication → Providers → Email เปิด Email ไว้ (ลิงก์เข้าสู่ระบบทางอีเมลใช้ได้เลย) · ถ้าไม่ต้องการให้ยืนยันอีเมลตอนสมัครด้วยรหัสผ่าน ให้ปิด "Confirm email"
  6. ตัวส่งอีเมลเริ่มต้นของ Supabase ส่งได้น้อยมากต่อชั่วโมง (ไว้ทดสอบ) ถ้ามีครูหลายคน ให้ตั้ง Project Settings → Authentication → SMTP ใช้บริการส่งอีเมลของตัวเอง

ไฟล์สำรองข้อมูล

เก็บวิชา เฉลย และผลคะแนนทั้งหมด ใช้ย้ายข้อมูลระหว่างคอมกับมือถือ การนำเข้าจะแทนที่ข้อมูลปัจจุบันในเครื่อง
